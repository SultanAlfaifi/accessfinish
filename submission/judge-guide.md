# Review AccessFinish in three minutes

1. **Open the page** (https://sultalfaifi.com/accessfinish/, or `npm run replay` → http://127.0.0.1:4178). It opens on the keyboard case and replays a recorded live run; **Pause** or **Show all** to take over.
2. **Keyboard case: a real upstream bug, fixed by Nemotron with no root cause supplied.** Click attempt 2's red verify step: the page said *booked*, the database held 1 Nov instead of 2 Nov, and the timeline names the code that changed the typed date (`onMonthChange → getUnavailableDates → applyUnavailableDates → setDate`). Attempt 4 saves the right date but reopening shows today, a second bug. Attempt 6 is verified; download its patch from the proof card. This is the gate at work: 77 such false "booked" pages across 27 keyboard runs, none accepted.
3. **Phone case (the second tab): our seeded calibration control.** The confirmation page said success but the database held the wrong phone. Nemotron's diagnosis and one-line diff, then the proof card with the saved row, the fresh-browser reopen and nine checks. Verified in 27 of 27 live runs.
4. **Every run, including failures:** the **Evidence** page lists all 54 live runs with replay links and raw traces (filter by case or verified), the results per agent version (keyboard fixed in 2 of 10 runs of agents v4–v5, 2 of 27 overall), and Nemotron's usage on Token Factory.
5. **What "verified" does and doesn't prove** is stated on the page and in the README: the verifier types the date into the field its acceptance checks name, so arrow-key use of the calendar grid is not checked.
6. **Run it yourself** (Node 22+, Docker): `npm run demo:setup`, set `NEBIUS_API_KEY`, then `node scripts/agent.cjs --case keyboard-date`. `node scripts/pr-comment.cjs` renders the merge-gate comment from a recorded run.

Where NVIDIA is used: every diagnosis, code search and edit comes from `nvidia/nemotron-3-super-120b-a12b` on Nebius Token Factory (`lib/agent.cjs`). The verifier is deterministic and never calls a model.
