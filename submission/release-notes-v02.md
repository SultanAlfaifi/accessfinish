# AccessFinish v0.2 — source repair with outcome verification

Review an AI-generated booking repair, approve its exact hash, and execute it in a fresh isolated Easy!Appointments fixture. Verified status requires the keyboard task, independent stored data, fresh reopen and fixed regression controls.

- Portable fixture from public pinned inputs; no host npm dependencies.
- Separate proposal and execution identities; stale evidence cannot verify another patch.
- Native keyboard task, SELECT-only reader, fresh reopen, preservation and pointer/date/calendar controls.
- English recorded review with all five frozen outcomes.
- Node.js 22/24 checks on Windows/Linux and independent clean Linux reproduction.

Measured result: **2/5 complete passes on one guided, exposed case**, with every failure retained. The diagnosis and repair direction were supplied to Nemotron. Estimated additional model cost for all eight requests: **$0.0394581 before tax**. Reproduction makes no model request.
