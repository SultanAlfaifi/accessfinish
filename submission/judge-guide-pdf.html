Review it in three minutes

  1. Open the page. It opens on the keyboard case and replays a recorded live run; press Pause or Show all to take over. Offline: npm run replay → http://127.0.0.1:4178.
  2. Keyboard case: a real upstream bug in Easy!Appointments, fixed by Nemotron with no root cause supplied. Click attempt 2’s red verify step: the page said booked, the database held 1 Nov instead of 2 Nov, and the timeline names the code that changed the typed date (onMonthChange → getUnavailableDates → applyUnavailableDates → setDate). Attempt 4 saves the right date but reopening shows today — a second bug. Attempt 6 is verified; download its patch from the proof card.
  3. Phone case (second tab): our seeded control. The confirmation page said success but the database held the wrong phone: Nemotron’s diagnosis and one-line diff, then the proof card with the saved row, the fresh-browser reopen and nine checks.
  4. Every run, including failures. The Evidence page lists all 54 live runs with replay links and raw traces, the results per agent version (v1–v5), and Nemotron’s usage on Token Factory.
  5. Run it yourself (Node 22+, Docker): npm run demo:setup, set NEBIUS_API_KEY, then node scripts/agent.cjs --case keyboard-date.

Where NVIDIA and Nebius are used

Every diagnosis, code search and edit comes from nvidia/nemotron-3-super-120b-a12b through Nebius Token Factory’s OpenAI-compatible API, with three tools: search_code, read_file (read-only) and propose_repair (lib/agent.cjs). The verifier is deterministic and never calls a model: it builds each candidate in an offline Docker sandbox and checks the keyboard booking, a read-only database read-back, a fresh-browser reopen and regressions (mouse booking with different data, cleared date, reserved slot, untouched records, sandbox isolation).

Synthetic data in a pinned copy of open-source Easy!Appointments (GPL-3.0). Two journeys today; the phone fault was seeded on purpose. The 54 published runs were made live on GitHub Actions, 24–26 October 2026; the demo video is a screen recording of a further live run on 29 October.
