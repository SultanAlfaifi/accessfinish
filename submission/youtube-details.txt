Title
AccessFinish | Keyboard repair to verified booking | Nebius x NVIDIA Hackathon

Description
AccessFinish connects a keyboard accessibility source repair to evidence that the user's task actually finished.

This 91-second demonstration shows the review workbench, a three-edit proposal authored by NVIDIA Nemotron 3 Super on Nebius Token Factory, and a new read-only verification of the saved booking in an isolated Easy!Appointments development fixture.

The operator supplied the defect diagnosis. The controller normalized source line endings without changing the semantic edits, built 83 JavaScript files, completed the keyboard booking, and verified storage and a fresh-browser reopen. This is one guided, exposed development case, not a general autonomous repair benchmark or a screen-reader user study.
