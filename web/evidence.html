How the agent improved

Each version changed the loop after reading the previous version's failed runs; from v2 on, results are never mixed across versions (v1 groups the pre-versioning runs). Each version ran 5 keyboard and 5 phone runs (v1: 7 each), one square per run below. The keyboard case has two bugs: the typed date is reset by page code, and reopening a booking resets it again. "Saved correctly" counts runs in which some attempt fixed the first.

Earlier single-shot trials

Before the agent, we measured single-shot, operator-guided repairs: five frozen Nemotron requests on the keyboard case gave 2 of 5 full passes. There the operator supplied the diagnosis and each proposal got one try, with no feedback. Every request, response and execution is kept in evidence/competition-20261021, with a guide to all the evidence in evidence/README.md.
