How the agent improved

Each version changed the loop after reading the previous version's failed runs; from v2 on, results are never mixed across versions (v1 groups the pre-versioning runs). The keyboard case has two bugs: the typed date is reset by page code, and reopening a booking resets it again. "Saved correctly" counts runs in which some attempt fixed the first.
